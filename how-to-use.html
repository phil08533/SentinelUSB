Field guide

How to use SentinelUSB.

From ISO to scan report. The basic workflow is deliberately simple.

1. Make the USB

Download the latest ISO, then use a USB imaging program such as balenaEtcher to write it to a spare USB drive.

Warning: flashing an ISO normally erases the selected USB. Double-check the destination before starting.

2. Boot the computer

Insert the SentinelUSB drive and boot from USB using the computer's boot menu or firmware settings. Once at the SentinelUSB prompt, type drives.

sentinelusb> drives

3. Scan a target

Choose the target partition shown by drives, then run:

sentinelusb> scan /dev/nvme0n1p3

The target is mounted read-only by default. SentinelUSB detects supported Windows, Linux and macOS filesystems, then runs malware, YARA and persistence checks.

4. Read the results

When the scan finishes, SentinelUSB reports the finding count and saved report location. Reports contain HTML and JSON, plus the ClamAV log when available.

A finding is a lead to investigate, not automatic proof that a file is malicious. Review the path, engine, rule and context before taking action.

5. Update when online

The base workflow can run offline. When the live environment has Internet access, ClamAV definitions can be updated before a scan.

Safety rules

  • Only inspect computers you own or are authorized to inspect.
  • Keep the default read-only behavior during investigation.
  • Do not delete suspicious files just because one scanner flags them.
  • If a volume is hibernated, encrypted, or inaccessible, do not force a write mount.
  • Keep copies of reports before making remediation changes.
