The person behind the project

Hi. I'm Phil.

I built SentinelUSB as a hands-on cybersecurity project: something small enough to understand, useful enough to actually boot, and open enough for other people to improve.

Why I built it

I wanted a rescue environment that starts outside the installed operating system and focuses on a practical question: what can I find on this computer without trusting the computer's normal environment?

That means read-only investigation by default, established security tools, simple reports, and a workflow that does not require an account or cloud service.

What I'm learning

SentinelUSB ties together Linux, Python, filesystem handling, malware scanning, YARA rules, bootable media, CI builds, documentation and defensive security thinking.

Build something real. Test it. Break it. Fix it. Then make it easier for the next person.

What's next

The project is still growing. Future work includes broader registry coverage, optional quarantine, stronger end-to-end testing, and release hardening.
