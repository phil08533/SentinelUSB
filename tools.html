Under the hood

The tools.

SentinelUSB wraps established Linux security and filesystem utilities with its own detection and reporting layer.

Antivirus

ClamAV

Performs recursive antivirus scanning against the mounted target. Its signatures can be updated when the live environment has network access.

Rules

YARA

Matches files against SentinelUSB's local rules, including suspicious scripting patterns such as encoded PowerShell and Windows Script Host usage. These are indicators, not verdicts.

Filesystem

libfsapfs / fsapfsmount

Provides userspace APFS access for supported macOS volumes, keeping SentinelUSB's APFS workflow read-only.

Detection

OS and persistence checks

Identifies Windows, Linux and macOS installations and checks common persistence locations such as startup folders, scheduled tasks, systemd units, cron directories, launch agents and shell startup files.

Storage

lsblk + blkid

Provides block-device and filesystem information so the scanner can enumerate drives and choose appropriate mounting behavior.

Integrity

SHA-256

Reported files can receive SHA-256 hashes when they are within the configured hashing limit, making observations easier to document and compare.

Reports

HTML + JSON

Each scan is organized into a timestamped report directory. HTML is for people; JSON is for later automation and analysis.
