SentinelUSB is a bootable Linux security environment designed to inspect Windows drives for common malware, suspicious files, and persistence mechanisms without relying on the installed operating system.

A rescue disk built for security.

SentinelUSB is intended to give you a clean environment for investigating a potentially compromised computer.

Boot from USB

Start outside the installed Windows environment so the scanner can inspect the system without depending on Windows being healthy.

Malware scanning

Use established detection engines and rules to identify known malware and suspicious files instead of pretending to replace commercial antivirus overnight.

Persistence checks

Inspect common Windows startup locations, scheduled tasks, services, scripts, and other mechanisms attackers can abuse.

Read-only by default

Analysis should start conservatively. SentinelUSB is designed to minimize accidental modification of the drive being investigated.

Offline capable

Take the toolkit to a machine without Internet access. Updated definitions can be supplied when connectivity is available.

Useful reports

Turn scan results into readable HTML and machine-friendly JSON reports for documentation and follow-up.

Three steps to get started.

You do not install SentinelUSB onto the computer you are investigating. You boot it from a USB drive.

01 — Download

Get the ISO

Download the latest SentinelUSB ISO from the project releases.

02 — Flash

Write it to USB

Use balenaEtcher to select the ISO, select your USB drive, and flash it.

03 — Boot & scan

Start SentinelUSB

Boot the target computer from the USB, select the Windows drive, and begin the scan.

Important: Flashing an ISO erases the selected USB drive. Double-check the drive before flashing. SentinelUSB is a security tool, not a guarantee that a system is malware-free.
